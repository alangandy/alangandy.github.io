CodeTeach.ai — GitHub Assignment Templates with Autograding

CodeTeach.ai helps programming instructors generate, review, validate, and deploy a complete assignment package. Start with an idea, document, starter, or solution; finish with an instructor-owned private GitHub template repository and a tested GitHub Actions autograder.

1. Seed 2. Review 3. Deploy
  • ✓ Generates starter code, solution, tests, instructions, README, and required support files
  • ✓ Supports Python, Java, JavaScript, TypeScript, C++, C, C#, Go, Rust, Ruby, SQL, and Jupyter notebooks
  • ✓ Runs the solution, tests, and assignment package in isolated sandboxes before deployment
  • ✓ Builds and verifies the GitHub Actions autograding workflow against the approved solution
  • ✓ Deploys a private template repository with an instructor-controlled solution repository or branch

StudyStride.ai — Voice and Browser Evidence, Ready to Review

StudyStride turns a user-started browser session into a reviewable record. Learners, instructors, and professionals can speak while working through visible browser content, then review the transcript, selected evidence, AI summary, and candidate questions before anything is shared.

  • ✓User-controlled microphone and authorized-tab capture with visible start and stop controls
  • ✓Transcript, grounded AI summaries, and candidate questions kept private for review
  • ✓Google Docs and Drive outputs, optional audio, and a selected-screenshot Browser Review PDF
  • ✓Useful for oral assignments, source critique, code review, data interpretation, and workflow reflection
  • ✓AI organizes evidence; the learner reviews the record and the instructor makes the judgment
